# narration_ja — 日本語ナレーション（確定稿・シーンごとに1ブロック）

build_video.py がパースする。`## N` 見出しでシーン開始。0=タイトルカード,
9=エンドカード（録画不要）。固有名詞の読みは build_video.py の置換マップが処理
（shinyExametrika→シャイニーエグザメトリカ, kosugitti→コスギッチ 等）。

## 0
shinyExametrika。コードを書かずに，テストデータ分析をブラウザで。

## 1
これは，exametrika パッケージの機能を，ブラウザだけで使える Web アプリ，shinyExametrika です。
最初に開くこのページに，使い方が4つのステップでまとめてあります。
データを読み込み，型を整え，分析を実行し，結果を見る。
やり方はここに書いてありますので，まずはこの流れに沿って進めていきましょう。

## 2
すぐに試したいときは，組み込みのサンプルデータが使えます。
Data タブを開いて，データソースでサンプルを選び，15項目・500人の二値データを読み込みます。
右側に，データのプレビューが表示されました。

## 3
実際の分析では，自分の CSV ファイルを読み込みます。ここが大事なところなので，丁寧に見ていきましょう。
データソースをアップロードに切り替えて，手元のファイルを選びます。
読み込んだら，まず，どの列が受験者の ID かを指定します。
次に，分析に使う列を選びます。ID やグループのような，分析に使わない余分な列は，ここで外しておきます。
未回答を表す数字があれば，欠測値コードに入力します。今回は99です。
回答のタイプは，自動判定のままにしておきます。
Format Data を押すと，データが整形され，画面の左上に，今読み込んでいるデータの形が表示されます。二値データ，と判定されました。
正しく読み込まれているかどうかは，整形済みデータのタブで確認しましょう。

## 4
shinyExametrika は，4つの回答タイプに対応しています。
二値のほか，5段階評定のような順序データ，順序のない名義データ，そして採点データです。
採点データのときは，回答のタイプで Rated を選ぶと，正答キーの入力欄が出てきます。
各項目の正しい選択肢を，項目の順番にカンマ区切りで入力します。
このように，データの性質に合わせて読み込めます。

## 5
データが準備できると，それに合う分析タブが選べるようになります。
例として，項目応答理論をやってみましょう。IRT タブでモデルを選び，実行します。
各パラメータは，はてなマークにカーソルを合わせると説明が出ます。
実行すると，モデルの適合度，項目ごとの識別力と困難度，そして被験者の能力値が表示されます。
プロットのタブでは，項目特性曲線が描かれます。曲線が右にあるほど，難しい項目です。

## 6
結果は，すべて保存できます。
左のサイドバー，実行ボタンの下に，出力のボタンがまとまっています。
適合度・項目母数・被験者母数を，それぞれ CSV で。
あるいは，分析結果を一括で，複数シートの Excel ファイルとして保存できます。
さらに，R スクリプトのボタンを押すと，今のセッションでおこなった操作を再現する，R のスクリプトが手に入ります。
画面で試して，コードで再現する。そんな使い方ができます。

## 7
ほかにも，潜在クラス分析やバイクラスタリングなど，多くのモデルが揃っています。
たとえばバイクラスタリングでは，受験者と項目を同時にグループ分けして，
並べ替えた反応パターンを，ヒートマップで見ることができます。

## 8
画面右上のトグルで，日本語と英語を，いつでも切り替えられます。
コードを書かずに，アップロードして，ボタンを押すだけ。
shinyExametrika で，テストデータ分析を始めてみてください。

## 9
exametrika は，R のパッケージとしても公開されています。R からも，ぜひ使ってみてください。
