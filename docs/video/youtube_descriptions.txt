-- Title --
shinyExametrika: Test Data Analysis in Your Browser — No Coding Required

-- Description --
exametrika is now a web app!
Meet shinyExametrika — a web app that lets you use exametrika right in your browser, with no coding required. This walkthrough covers the whole flow: loading your data, setting the response type, running an analysis, and downloading both the results and a reproducible R script.

App
https://kosugitti.shinyapps.io/shinyExametrika/

Source code (GitHub)
